Yakai Zheng
2018-10-20
项目实战
springcloud

项目背景

Spring Cloud 项目，有前端，有后端，后端服务整合了 Cloud Security OAuth2 ，请求后端的服务需要携带认证信息，即请求头中需要携带” Authorization Bearer …“ 的Token 头信息。

后台微服务还存在服务之间采用 Fegin 的调用，在前端请求后端时，是携带 Token，可以正常请求响应的，但是当微服务之间调用时，报：
